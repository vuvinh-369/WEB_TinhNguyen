# Trăng Sáng Langbiang — landing page concept

A responsive, static Vietnamese landing page built from the supplied design system. Open `index.html` in a browser, or serve this folder with `python3 -m http.server 8000` and visit `http://localhost:8000`.

The page includes a photo slider, responsive navigation, and a persistent light/dark switch. Calls to action link to the project's existing fundraising, history, news, Facebook, and email destinations. Display fonts load from Google Fonts; the page remains usable with its sans-serif fallback if fonts are unavailable.

Photography and the logo are from [Trăng Sáng Langbiang](https://trangsang.vn/), referenced in the supplied design guidance and the project's gallery. This is a landing page concept, not a replacement for the live website.
